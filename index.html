Projets

Surveillance et facturation eau/électricité en temps réel

Problème : suivre la consommation d'eau et d'électricité de plusieurs maisons, détecter automatiquement les pannes de compteur et les coupures, et facturer chaque client en fin de mois.

Données : relevés de 6 compteurs simulés toutes les 10 secondes (en attendant de vrais capteurs de débit et de courant), stockés dans PostgreSQL.

Méthode : pipeline de streaming avec Kafka, détection des pannes et coupures en Python, API REST + WebSocket pour les alertes en temps réel, dashboard React, génération de factures PDF envoyées par courriel chaque mois.

Résultat : chaîne complète fonctionnelle de bout en bout, déployée sur Kubernetes (Minikube) avec CI/CD automatique via GitHub Actions.

  • Python
  • Kafka
  • PostgreSQL
  • React
  • Docker
  • Kubernetes
  • GitHub Actions

Segmentation de clientèle avec K-means

Problème : regrouper les clients en segments homogènes pour mieux comprendre leurs comportements d'achat et mieux cibler les actions marketing.

Données : base de clients avec plusieurs variables (profil, habitudes d'achat, montants dépensés), nettoyées et normalisées avant l'analyse.

Méthode : algorithme de clustering K-means, avec choix du nombre de segments et visualisation des groupes obtenus.

Résultat : des segments de clients bien distincts, chacun avec un profil d'achat différent, permettant d'adapter les actions à chaque groupe.

  • Pandas
  • scikit-learn
  • K-means

Modification d'images par Deep Learning

Problème : modifier automatiquement des images à l'aide d'un modèle de deep learning, sans retouche manuelle.

Données : jeu d'images prétraitées (redimensionnement et normalisation) pour l'entraînement et le test du modèle.

Méthode : réseau de neurones profond entraîné pour transformer les images, avec suivi de la qualité des résultats pendant l'entraînement.

Résultat : un modèle capable de produire des images modifiées à partir d'images d'entrée.
